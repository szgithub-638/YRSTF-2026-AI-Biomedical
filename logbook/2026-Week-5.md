Week 5 — Transfer Learning Model Development

Objective:
Improve the melanoma detection AI model by implementing transfer learning and organizing the dermatology dataset for supervised learning.

Work Completed:
• Organized the ISIC 2019 dataset into labeled class folders (benign vs malignant).
• Wrote a Python preprocessing script to automatically sort over 25,000 dermoscopic images based on diagnosis labels.
• Implemented transfer learning using the MobileNetV2 convolutional neural network architecture.
• Trained the model using TensorFlow and Keras with a training/validation dataset split.
• Integrated the trained model into the existing prediction pipeline.

Challenges Encountered:
Initially the model detected zero images because TensorFlow requires class-labeled directories. This was resolved by writing a dataset organization script that automatically sorted the images according to diagnosis labels.

Results:
The trained model achieved approximately 83% validation accuracy when classifying skin lesions as benign or malignant. This demonstrates the potential of machine learning models to assist with early melanoma detection using medical imaging.
