\# MelanoScan AI 🔬

\### Using Artificial Intelligence to Detect Early Signs of Skin Cancer



\## Overview

Melanoma is the most dangerous form of skin cancer, with over 300,000 new cases diagnosed globally each year. When detected early, the 5-year survival rate exceeds 90%.



This project investigates whether deep learning can analyze dermatology images and detect visual patterns indicating potential melanoma — supporting earlier screening and awareness.



\## Built With

\- Python

\- TensorFlow / Keras

\- scikit-learn

\- Pandas

\- Grad-CAM (visual explainability)



\## Project Structure

\- `model/` — Trained Keras models and training scripts

\- `app/` — Streamlit web app for image prediction

\- `testing\_images/` — Sample benign and melanoma images

\- `logbook/` — Weekly research and development log
